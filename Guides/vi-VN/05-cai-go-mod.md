# Xử lý xung đột

## Khi app phát hiện mod cũ

1. Đọc đường dẫn file được cảnh báo.
2. Dùng **Cách ly** nếu muốn giữ bản sao có thể khôi phục, hoặc **Xóa xung đột** khi chắc chắn không cần.
3. Bấm **Quét lại mod**.
4. Chỉ cài khi trạng thái không còn xung đột.

## App bảo vệ file như thế nào

- Chỉ quản lý file có trong manifest của VHWuWa.
- So sánh SHA-256 trước khi gỡ để tránh xóa nhầm file đã bị mod khác ghi đè.
- Giữ nguyên mod skin không trùng đường dẫn nạp của Việt hóa.

> Luôn tắt game trước khi cách ly, xóa, cài hoặc gỡ file mod.
