# Cài / Gỡ mod

Vào tab **Quản lý mod**:

- **Cài mod:** bấm **➕ Cài mod**, chọn file `.vhwpack`.
- **Gỡ mod:** chọn mod trong bảng → bấm **🗑 Gỡ mod đã chọn**.
- **Kiểm tra lại:** bấm **🔍** để làm mới danh sách.

Dòng trên cùng cho biết đang cài bản **Hán Việt** hay **Tiếng Anh**, và font đang dùng.
