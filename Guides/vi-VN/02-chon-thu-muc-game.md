# Chọn thư mục game

## Cách nhanh nhất

1. Mở **Trang chủ** rồi bấm **Tự tìm game**.
2. Xem lại đường dẫn và trạng thái nhận diện game.

## Nếu app không tự tìm thấy

Bấm **Chọn thư mục** và chọn thư mục Wuthering Waves chứa thư mục con `Client`, ví dụ:

```text
D:\Game\Wuthering Waves Game
D:\SteamLibrary\steamapps\common\Wuthering Waves\Wuthering Waves Game
```

Đây là đường dẫn ví dụ, không phải vị trí bắt buộc. **Không chọn riêng thư mục `Client` hoặc file EXE.** Sau đó bấm **Kiểm tra**.

Nếu chỉ có launcher hoặc đường dẫn game đã bị chuyển, ứng dụng có thể báo **Chưa có game PC**. Nút cài Việt hóa sẽ không tự mở khóa cho tới khi nhận diện đúng client và xác minh dữ liệu tương thích.
