# Cài Việt hóa

1. **Tắt game hoàn toàn.**
2. Chọn đúng thư mục game và bấm **Kiểm tra file**.
3. Vào **Cài Việt hóa**. App sẽ kiểm tra bản Việt hóa/mod đang cài; nếu phát
   hiện file có thể xung đột, hãy gỡ bản cũ trước.
4. Chọn kiểu tên:
   - **Tên Anh**: Jinhsi, Changli, Yangyang, Suisui…
   - **Hán Việt**: Kim Tịch, Trường Ly, Ương Ương, Tuệ Tuệ…
5. Giữ **Cài kèm font tiếng Việt** để chữ có dấu hiển thị đúng.
6. Bấm **Cài Việt hóa** và chờ hậu kiểm hoàn tất.

App chỉ báo thành công khi PAK, SIG, font, loader và marker đã được sao chép đủ
và khớp SHA-256. Nếu có file thiếu/sai, không mở game; đọc tên file lỗi trong
thông báo rồi cài lại.

Sau khi cài:

- Ngôn ngữ chữ trong game: **English**.
- Chế độ khởi chạy: **DirectX 11**.
- Đổi Tên Anh/Hán Việt bằng cách chọn lại biến thể và cài lần nữa.

Bản 2.0.0 dùng tập 85 DB đã kiểm chứng, có đầy đủ kỹ năng 3.4–3.6 và cốt truyện
chính 3.6. UID được thay bằng ký tự trắng.
