# WuWa Việt Hóa PC v3.0.21

**Đã sửa**
- Khắc phục lỗi nút **Cài Việt hóa** không hoạt động khi chọn tên Hán Việt hoặc font tiếng Việt.
- Cài đặt tự sử dụng bản dịch hiện có và thông báo rõ sau khi hoàn tất.

**Lưu ý:** Gói hiện tại chưa hỗ trợ tên Hán Việt và font tùy chỉnh.

**Cập nhật:** Mở ứng dụng → **Cài đặt → Kiểm tra cập nhật**, hoặc tải bản ZIP bên dưới.
