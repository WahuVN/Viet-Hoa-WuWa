# WuWa Việt Hóa PC v3.0.19 · R29

Bản PC mới bổ sung PAK Việt hóa **R29** (dữ liệu game 3.8.11) và cải thiện giao diện, thao tác cài đặt.

**Điểm mới**
- Cài/gỡ R29 bằng Mount phụ, không dùng DLL loader cũ; chỉ cho cài khi game được xác minh tương thích.
- Đồng bộ màu, nút bấm và trạng thái game; hướng dẫn người mới rõ ràng hơn.
- Giữ ZIP portable và tự cập nhật: hỏi trước khi tải, kiểm tra SHA-256, có sao lưu/khôi phục; bảo vệ dữ liệu editor.

**Cài đặt**
- Đang dùng **3.0.18**: mở ứng dụng, chọn **Có** khi được hỏi cập nhật.
- Cài mới: tải `VietHoa-WuWa-v3.0.19.zip`, giải nén ra thư mục cố định rồi chạy `VHWuWa.exe`.
- Đóng game, chọn đúng thư mục và bấm **Cài Việt hóa** khi app xác nhận tương thích. Trong game đặt **Text Language = English**.

**Lưu ý:** R29 hiện chỉ hỗ trợ **Tên Anh**; chưa hỗ trợ Hán Việt hoặc PAK font rời. Đợt này **không có bản Android mới**. Game/resource chưa xác minh sẽ bị khóa cài.
