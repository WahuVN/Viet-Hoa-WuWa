Cải thiện bố cục trang chủ và hiển thị ở nhiều kích thước cửa sổ.

### Thay đổi
- **Trang chủ:** tự điều chỉnh để thấy ngay trạng thái game, chọn thư mục, cài Việt hóa và mở game **không cần kéo xuống**.
- **Cửa sổ nhỏ:** các nút và thông tin vẫn nằm trong một màn hình; giữ nguyên menu và chức năng đang có.
- **Tài liệu GitHub:** cập nhật hướng dẫn, ảnh giao diện và liên kết tải.

**Bản dịch:** Giữ nguyên R29 (3.8.11), không thay đổi nội dung game.

**Cập nhật:** Vào **Cài đặt → Kiểm tra cập nhật** hoặc tải ZIP bên dưới, giải nén và chạy `VHWuWa.exe`.
