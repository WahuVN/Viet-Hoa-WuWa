# WuWa Việt Hóa PC v3.0.23 — Giao diện gọn, mở game dễ hơn

**Wuthering Waves PC R29 / resource 3.8.11.**

- **Trang chủ:** nhóm rõ 3 bước **Chọn game → Cài Việt hóa → Mở game**; nút mở game rõ hơn trên ảnh nền; hiển thị trạng thái chọn/cài game.
- **Mở game:** ghi rõ chương trình mở qua launcher chính thức hoặc Steam; nhấn **Start** trong launcher để chơi.
- **Đóng game:** thêm xác nhận, ưu tiên thoát bình thường và chỉ buộc dừng tiến trình đúng thư mục game khi người dùng đồng ý. Watchdog kiểm tra an toàn 30 giây và không tự tắt launcher.
- **Giữ nguyên R29**, font mặc định **Lexend 660**, thư viện 73 font, mod ngoài và cơ chế cập nhật có SHA-256/rollback.

**Cập nhật:** Vào **Cài đặt → Kiểm tra cập nhật**, hoặc tải ZIP, giải nén và mở VHWuWa.exe. Chọn đúng thư mục game có Client.

**Lưu ý:** Gói Windows chưa có chữ ký nhà phát hành (Authenticode), vì vậy Windows có thể cảnh báo. Điều này không phải lỗi SIG của game; ứng dụng vẫn kiểm tra SHA-256. Dọn tiến trình chạy ẩn đã qua QA giả lập, chưa nghiệm thu với game thật.
