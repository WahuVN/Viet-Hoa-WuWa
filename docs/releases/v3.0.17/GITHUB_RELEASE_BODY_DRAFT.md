VHWuWa **3.0.17** chủ yếu cập nhật phần cài Việt hóa và font chữ.

### Thay đổi
- Giao diện cài đặt gọn hơn, chỉ để nút **Cài Việt hóa** nổi bật; các chức năng gỡ, xóa hoặc cách ly mod được đưa vào **Tùy chọn khác**.
- Kiểm tra kỹ hơn trước khi cài/gỡ, giữ file game và backup, kiểm tra SHA-256 sau cài.
- Thêm **Lexend Variable** mặc định **weight 650**, chỉnh độ đậm 100–900, xem trước tiếng Việt và tạo font trước khi áp dụng.
- Giữ 72 font cũ, tổng cộng **73 font**.

**Lưu ý:** Khi cài, app có thể tự xóa những mod xung đột được nhận diện. Muốn giữ mod thì chọn **Cách ly mod cũ** trước.

### Cách cài
Tải bộ cài chính thức, giải nén toàn bộ và mở `VHWuWa.exe`. Tắt game/launcher trước khi cài. Trong game đặt Text Language = English.

### File phát hành (chưa có)
- `VietHoa-WuWa-v3.0.17.zip`
- `WuWaVH_EN_99_P.pak`
- `WuWaVH_HanViet_99_P.pak`

**Chưa có link và SHA-256 vì bản 3.0.17 chưa build.** Nội dung dịch mới chỉ ghi sau khi QA xong; Android/App-Dịch theo bản riêng.
