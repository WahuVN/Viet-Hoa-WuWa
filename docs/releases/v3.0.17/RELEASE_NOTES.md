Bản cập nhật VHWuWa 3.0.17 tập trung vào việc cài Việt hóa ổn định hơn và bổ sung font Lexend. **Hiện đang chuẩn bị, chưa phát hành.**

### Có gì mới?

- **Giao diện cài đặt gọn hơn:** chỉ hiện nút **Cài Việt hóa** ở phần chính. Nút gỡ, quét, xóa và cách ly mod nằm trong **Tùy chọn khác** (mặc định đóng). Khi xóa mod thủ công, app vẫn hỏi xác nhận.
- **Cài đặt an toàn hơn:** kiểm tra file đang bị khóa, game còn chạy, file quản lý của WAHU và các bản sao lưu trước khi thay đổi. Sau khi cài có thông báo số file mod đã dọn.
- **Thêm Lexend Variable:** mặc định độ đậm 650, có thể chỉnh weight 100–900. Xem trước tiếng Việt có dấu rồi tạo font để áp dụng vào game.
- **Thư viện 73 font:** giữ nguyên 72 font cũ. Font không hỗ trợ chỉnh độ đậm sẽ tự khóa thanh kéo.

### Cài đặt

Tắt game và launcher, chọn đúng thư mục game trong VHWuWa rồi cài như bình thường.

**Quan trọng:** Khi cài Việt hóa, app có thể xóa vĩnh viễn các mod xung đột đã nhận diện. Nếu muốn giữ lại, hãy bấm **Cách ly mod cũ** trước khi cài.

Để đổi font: vào **Font chữ → Lexend Variable → Weight 650 → Tạo & áp dụng**.
