# Thông báo v3.0.17 (bản nháp, chưa đăng)

**VHWuWa 3.0.17 – đang chuẩn bị cập nhật**

Bản này mình tập trung sửa phần cài Việt hóa và bổ sung font mới.

- Giao diện cài Việt hóa gọn hơn, chỉ để nút **Cài Việt hóa** nổi bật. Gỡ, xóa hoặc cách ly mod được gom trong **Tùy chọn khác**.
- Kiểm tra file trước khi cài/gỡ, tránh đụng nhầm file game, file Việt hóa hoặc bản sao lưu.
- Thêm **Lexend Variable**, mặc định độ đậm **650**. Có thể kéo thanh chỉnh từ 100–900 và xem trước chữ tiếng Việt trước khi áp dụng.
- Giữ nguyên 72 font trước đó, tổng cộng **73 font**.

**Lưu ý:** Khi cài, app có thể tự xóa các mod xung đột được phát hiện. Nếu muốn giữ mod đang dùng, hãy chọn **Cách ly mod cũ** trước khi cài.

Phần Việt hóa trong game và bộ cài mới vẫn đang kiểm tra. **Chưa có link tải 3.0.17**. Khi phát hành chính thức mình sẽ đăng link GitHub.

Gặp lỗi chữ hoặc dịch chưa ổn thì mọi người dùng `/bao-loi` hoặc `/gop-y`, gửi thêm ảnh để mình kiểm tra.
