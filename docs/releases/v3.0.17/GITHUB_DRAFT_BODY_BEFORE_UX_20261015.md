# WuWa Việt Hoá PC v3.0.17

Bản cập nhật từ **v3.0.16 lên v3.0.17**. Bạn dùng phiên bản 3.0.16 có thể cập nhật trực tiếp ngay trong ứng dụng sau khi GitHub Release này được xuất bản ở chế độ **Stable/Latest**.

### Thay đổi
- Giao diện Windows mới gọn hơn: sidebar 8 mục, trạng thái lựa chọn rõ, header dễ đọc và bố cục thống nhất.
- Thư viện 73 font với Lexend 650 mặc định, hỗ trợ tuỳ chỉnh độ đậm/font theo công cụ PC.
- Cập nhật dữ liệu bản dịch Tên Anh / Hán Việt, bao gồm 12 key thoại Qingxiao theo gói QA.
- Gói cập nhật giữ nguyên cơ chế xác minh SHA-256, cấu hình và dữ liệu người dùng.

### Cập nhật từ v3.0.16
1. Mở WuWa Việt Hoá 3.0.16 khi có Internet.
2. Ở **Cài đặt**, bật **Tự động kiểm tra cập nhật khi mở app** (mặc định bật).
3. App sẽ báo **Có bản mới v3.0.17**. Nhấn **Có/Cập nhật** để tải và cài.
4. Nếu đã tắt tự kiểm tra, vào Cài đặt và bấm **Kiểm tra cập nhật**.

File cập nhật tự động bắt buộc mang tên `VietHoa-WuWa-v3.0.17.zip`. GitHub công bố SHA-256 của asset, ứng dụng sẽ kiểm tra mã băm trước khi cài.

### Tương thích và lưu ý
- Wuthering Waves Global 3.7, Windows x64.
- Tắt game trước khi cài/gỡ Việt hoá hoặc thay font.
- Kiểm thử offline nâng cấp từ 3.0.16 bằng updater thật đã PASS: từ chối SHA sai, cài đúng ZIP, giữ cấu hình, lên phiên bản 3.0.17.
- **Lưu ý:** phần tự cập nhật 3.0.16 → 3.0.17 đã qua kiểm thử, nhưng hiển thị font/thoại trực tiếp trong game vẫn chưa được xác nhận.

Gói Tên Anh và Hán Việt riêng dành cho các chức năng cập nhật/khôi phục dữ liệu đi kèm Release này.
