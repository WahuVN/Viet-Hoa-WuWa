# Hướng dẫn v3.0.17 (bản nháp)

### Cài Việt hóa
1. Tải bản chính thức từ GitHub sau khi phát hành, giải nén toàn bộ rồi mở `VHWuWa.exe`.
2. Tắt Wuthering Waves và launcher, chọn đúng thư mục game.
3. Nếu muốn kiểm tra mod xung đột thủ công, mở **Tùy chọn khác → Quét mod**. App vẫn tự kiểm tra khi cài.
4. Nếu cần giữ mod cũ, vào **Tùy chọn khác → Cách ly mod cũ** trước khi cài. Xóa mod xung đột là xóa vĩnh viễn.
5. Chọn Tên Anh hoặc Hán Việt và bấm **Cài Việt hóa ngay**. Khi chơi, đặt Text Language = English.

### Đổi sang Lexend
Vào **Font chữ**, chọn **Lexend Variable**, chỉnh **Weight 650** hoặc mức muốn dùng, xem thử tiếng Việt rồi bấm **Tạo & áp dụng**.

Danh mục có 73 font; Lexend đi kèm sẵn, một số font cũ vẫn phải tải khi chọn.

### Cập nhật từ bản cũ
Khi v3.0.17 được phát hành, mở app và cập nhật như bình thường. Updater sẽ cần kiểm tra đúng file và SHA-256 trước khi cài.

Nếu game đang chạy, file bị khóa hoặc app báo marker lỗi, hãy dừng thao tác và kiểm tra trước khi tiếp tục. Nếu lỗi font thì thử khôi phục font mặc định và gửi ảnh/log.

**Hiện chưa có bản 3.0.17 để tải và chưa kiểm thử trực tiếp trong game.**
